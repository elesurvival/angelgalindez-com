# Glimpse Brand Guide

## Project Name
Glimpse

## Tagline
Capture the glimpse before it fades.

## Purpose
Glimpse is a dream and subconscious-capture world for preserving the fragile fragments that appear between sleep, memory, reflection, and waking thought. It should feel quiet, intimate, cinematic, and app-quality: a small portal for catching meaning before it disappears.

## Visual Themes
- Crescent / eye / moon / portal mark
- Dream capture and subconscious memory
- Soft glow, night gradients, atmospheric depth
- Ethereal light against midnight indigo
- Quiet discovery rather than loud productivity

## Color Palette
Approximated from the supplied artwork:

| Token | Hex | Use |
| --- | --- | --- |
| Midnight Indigo | `#05061F` | Primary dark background |
| Deep Violet | `#44218F` | Brand depth and card gradients |
| Dream Violet | `#8F5BFF` | Primary accent glow |
| Lavender Mist | `#DCCBFF` | Soft highlights and text accents |
| Moon White | `#F7F4FF` | Symbol and high-contrast type |
| Cyan Glow | `#44D8FF` | Secondary luminous accent |
| Memory Blue | `#3F72E8` | App icon gradient support |

## Typography Direction
Use quiet, modern sans-serif typography with generous spacing. Recommended direction:
- Large editorial headings with light or regular weight
- Small uppercase labels with wide letter spacing
- Clean UI labels for app surfaces
- Avoid harsh tech fonts; Glimpse should feel more dreamlike than mechanical

## Logo Usage Notes
- `glimpse-logo-primary.png` is the preferred full logo for dark cinematic surfaces.
- `glimpse-logo-mark.png` is the standalone crescent / eye / portal mark.
- `glimpse-logo-white.png` works on dark, photographic, or gradient backgrounds.
- `glimpse-logo-dark.png` is reserved for light backgrounds.
- Preserve clear space around the mark so the glow can breathe.
- Avoid placing the mark on busy backgrounds without a dark veil or blur behind it.

## Website Page Direction
The future Glimpse page should feel like a quiet portal into dream capture:
- Cinematic dark hero with large atmospheric mark or moonlit background
- Violet/lavender/cyan glow accents
- Copy centered on preserving dream fragments before they fade
- Product sections that feel reflective and soft rather than dashboard-heavy
- Mobile app imagery can be introduced once real Glimpse screenshots exist
